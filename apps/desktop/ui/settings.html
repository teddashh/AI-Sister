正在讀 Azure 雲端朗讀狀態…

每份新答案完成後只自動送出該題答案正文原文一次；按答案下方的 Azure 重播會再送一次。 正文可能含姓名、電話與金額，且不先遮罩。不送截圖、來源連結、memory id、整份資料庫、 其他文字或角色選擇。你輸入金鑰時，它會 短暫經過這頁與 Tauri IPC；保存後欄位立即清空，長期只放 Windows Credential Manager， 不寫進 config.toml，也不會把已存值回傳到這一頁。回來的 MP3 只在記憶體播放， 不落地快取。取消會先停止播放並丟掉晚到的回應；已進入送出階段的 request 仍可能跑到逾時， 此時關閉開關、改區域／聲音、存刪金鑰、改第四張同意或原生取消，可能要等它結束才回覆。 任一操作回覆成功後，舊 request 不會才開始送。

區域、聲音、開關、金鑰與第四張同意書各自儲存，不跟頁尾的「儲存」混在一起。 沒有 request 正在送時會立即生效；若撞上既有 request，可能等它結束或最長 45 秒逾時。 操作成功後，四個條件缺任何一個，AI-Sister 都不會再送出新的 Azure request。

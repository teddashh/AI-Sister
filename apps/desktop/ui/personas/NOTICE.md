# AI-Sister 角色圖

這個目錄的 17 張 WebP 是素材所有人 Ted Huang 於 2026-09-08 明確提供給 AI-Sister
使用的角色素材，來源為
`teddashh/Multi-Ai-Chatapp` 的 canonical 角色圖。它們可以原樣收進 AI-Sister 的
source tree 與官方安裝包，但不包含在本專案的 Apache-2.0 程式碼授權裡。

角色名稱與造型是受同名 AI 產品啟發的虛構角色。AI-Sister 是獨立產品，未與相關
供應商合作、隸屬或獲其背書。檔案來源、大小與 SHA-256 固定在 `manifest.json`。

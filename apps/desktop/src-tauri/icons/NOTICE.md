# AI-Sister application icons

這個目錄的五個 PNG／ICO 是以 `apps/desktop/ui/personas/chatgpt.webp` 為人物來源，
按 `apps/desktop/icon/icon.html` 與 `scripts/make-icons.sh` 產生的官方應用程式圖示。

recipe、輸出 bytes 與 SHA-256 的 exact 五個衍生圖示輸入收進 AI-Sister source
tree，並按平台供官方 build 使用或內嵌。每份 artifact 只取該平台需要的格式，
不代表安裝包會原樣附帶五個檔案。這些圖像不包含在本專案的 Apache-2.0 程式碼
授權裡；這份授權不擴張原始人物素材、其他角色或未列出的衍生圖之權利範圍。
